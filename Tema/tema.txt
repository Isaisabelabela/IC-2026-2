HAR70+ — HUMAN ACTIVITY RECOGNITION 70+

1. TEMA DO PROJETO

Reconhecimento de Atividades Humanas utilizando Inteligência Computacional.

O objetivo do projeto é desenvolver um modelo de Inteligência Computacional capaz de reconhecer diferentes atividades humanas a partir de sinais obtidos por acelerômetros.

A ideia é que a IA receba dados de movimento capturados pelos sensores e aprenda a associar os padrões desses sinais às atividades realizadas pelos participantes.


2. SOBRE A BASE DE DADOS

A base utilizada será a HAR70+ (Human Activity Recognition 70+), disponibilizada pelo UCI Machine Learning Repository.

A base contém dados de 18 participantes com idade entre 70 e 95 anos. Os participantes utilizaram dois acelerômetros triaxiais durante aproximadamente 40 minutos em um protocolo semiestruturado realizado em condições próximas às atividades do cotidiano.

Os sensores foram posicionados:

- na região lombar;
- na coxa direita.

A base possui:

- 2.259.597 registros;
- 6 características de entrada;
- 18 participantes;
- dados multivariados e temporais;
- nenhuma informação faltante segundo o UCI;
- problema de classificação.


3. O QUE É UM ACELERÔMETRO?

Um acelerômetro é um sensor capaz de medir aceleração em diferentes direções.

Os acelerômetros utilizados possuem três eixos:

- X
- Y
- Z

Por isso, cada sensor gera três sinais.

Como são utilizados dois sensores, temos seis sinais:

Sensor da região lombar:
- back_x
- back_y
- back_z

Sensor da coxa:
- thigh_x
- thigh_y
- thigh_z


4. O QUE AS VARIÁVEIS REPRESENTAM?

As variáveis não representam diretamente a posição da pessoa.

Elas representam a aceleração medida pelo sensor em cada um dos três eixos.

Por exemplo:

back_x = aceleração medida no eixo X pelo sensor localizado nas costas.

thigh_z = aceleração medida no eixo Z pelo sensor localizado na coxa.

Esses valores são registrados continuamente ao longo do tempo.

Assim, podemos observar como a aceleração varia durante uma determinada atividade.


5. POR QUE OS DADOS PERMITEM IDENTIFICAR A ATIVIDADE?

Cada atividade produz diferentes padrões de movimento.

Por exemplo, durante uma caminhada, a aceleração da coxa e das costas tende a apresentar variações repetitivas.

Durante uma atividade sedentária, como ficar sentado, os sinais tendem a apresentar um comportamento diferente.

Durante o uso de escadas, os padrões de aceleração também se modificam.

A IA não recebe uma informação dizendo "a pessoa está caminhando".

Ela recebe os valores dos sensores e precisa aprender os padrões associados a cada atividade.


6. VARIÁVEL-ALVO

A variável que queremos prever é o label da atividade.

A base contém as seguintes categorias de atividade:

1 - walking
3 - shuffling
4 - stairs ascending
5 - stairs descending
6 - standing
7 - sitting
8 - lying

Portanto, o problema é de classificação multiclasse.

8. EXEMPLO CONCEITUAL

Uma sequência de sinais pode apresentar um padrão semelhante ao observado durante uma caminhada.

A IA recebe os valores dos sensores e, depois de ser treinada com exemplos, pode produzir:

Entrada:
dados dos acelerômetros

Saída prevista:
walking


9. CARACTERÍSTICA TEMPORAL

A HAR70+ é uma base de séries temporais.

Isso significa que a ordem dos registros importa.

Os sensores registram os movimentos ao longo do tempo, e não apenas valores independentes.

Por isso, uma atividade é melhor entendida observando uma sequência de medições.

No estudo original, os sinais foram segmentados em janelas de cinco segundos, contendo 250 amostras a 50 Hz, e características foram extraídas dessas janelas para o treinamento dos modelos.

Essa característica será importante para definir como os dados serão utilizados no projeto.


10. POR QUE ESSA BASE É INTERESSANTE PARA A DISCIPLINA?

A base permite realizar diversos experimentos de Inteligência Computacional.

Podemos testar:

- diferentes arquiteturas de redes neurais;
- diferentes números de camadas;
- diferentes números de neurônios;
- funções de ativação, como ReLU, Tanh e Sigmoid;
- diferentes métodos de inicialização;
- diferentes características de entrada;
- uso dos dados da coxa, das costas ou dos dois sensores;
- diferentes estratégias de pré-processamento;
- diferentes métodos de avaliação.

Dessa forma, o projeto pode evoluir ao longo dos desafios da disciplina.

12. AVALIAÇÃO

O desempenho do modelo poderá ser analisado utilizando métricas como:

- Accuracy;
- Precision;
- Recall;
- F1-score;
- Matriz de confusão.

A matriz de confusão será especialmente útil para verificar quais atividades são mais confundidas pelo modelo.


13. ESTUDO ANTERIOR

A HAR70+ foi apresentada e utilizada em um estudo publicado em 2023:

"Validation of an Activity Type Recognition Model Classifying Daily Physical Behavior in Older Adults: The HAR70+ Model"

Autores:
Astrid Ustad et al.

O estudo desenvolveu e validou um modelo de reconhecimento de atividades utilizando os dados de adultos mais velhos.

No estudo, foram utilizados acelerômetros e aprendizado de máquina para classificar comportamentos físicos.

Isso não impede a utilização da base no projeto da disciplina, pois a proposta do projeto será estudar diferentes configurações de Inteligência Computacional e analisar seu comportamento sobre a base.
